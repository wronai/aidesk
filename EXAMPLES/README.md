# EXAMPLES — Przykłady użycia Proxeen

Ten katalog zbiera gotowe scenariusze użycia dla różnych grup użytkowników.
Każdy plik pokazuje **realny workflow krok po kroku** z wykorzystaniem aktualnych funkcji projektu.

## Struktura

- `EXAMPLES/developer/fix-python-import-error.md`
- `EXAMPLES/developer/clipboard-relation-json-regex.md`
- `EXAMPLES/qa/regression-triage.md`
- `EXAMPLES/ops/health-monitoring-and-cost-control.md`
- `EXAMPLES/content_creator/translation-and-voice-tts.md`
- `EXAMPLES/plugin_author/create-first-plugin.md`

## Jak korzystać z przykładów

1. Wybierz grupę użytkownika najbardziej zbliżoną do Twojego przypadku.
2. Uruchom system (`make run`).
3. Przejdź przez kroki z wybranego pliku.
4. Dostosuj workflow do swojego środowiska (modele, OCR, STT, pluginy).

> Więcej kontekstu technicznego: `README.md`, `QUICKSTART.md`, `ARCHITECTURE.md`.
